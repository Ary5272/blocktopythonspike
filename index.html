SPIKE Blocks → Python

Drop in a SPIKE Prime word-block project (.llsp3) and get SPIKE 3 Python you can paste straight into a Python project in the SPIKE App. Your file never leaves your browser.

program.py

What gets converted?
  • Events: when program starts, when color is, when pressed, when distance, when button, when timer, when (condition), when I receive / broadcast, gestures, which face is up.
  • Movement: set movement motors (motor_pair.pair(motor_pair.PAIR_1, port.A, port.E)), move / steer for cm, inches, rotations, degrees or seconds, start / stop moving, movement speed, tank moves.
  • Motors: run for rotations/degrees/seconds, start, stop, set speed, go to position, relative position, power.
  • Light, sound, sensors: write, images, pixels, power-button light, beeps and notes, color, reflection, distance, force, buttons, yaw/pitch/roll, timer.
  • Control, operators, variables, lists and My Blocks (they become async def functions).

Speeds: block % is turned into degrees/second (100% ≈ 1000°/s). Blocks with no Python version get a # TODO comment in the code so nothing disappears silently.
