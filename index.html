Run it on your hub

  1. Easiest: click SPIKE project above and open that file in the SPIKE App (☰ → Open).
  2. Or paste it: in the SPIKE App make a New Project → Python, delete the starter code, paste, and press ▶.
  3. Speeds: a block's % becomes degrees per second (30% → velocity=300), the same as LEGO's own Python examples.
What gets converted?
  • Events: when program starts, button, color, pressed, distance, timer, gestures, orientation, when (condition), broadcasts.
  • Movement: movement motors (motor_pair.pair(motor_pair.PAIR_1, port.C, port.D)), move/steer for cm, inches, rotations, degrees or seconds, start/stop moving, tank moves, speed.
  • Motors: run for rotations/degrees/seconds, start, stop, speed, go to position, relative position, power.
  • Light, sound, sensors: write, images, pixels, power-button light, beeps and notes, color, reflection, distance, force, buttons, yaw/pitch/roll, gestures, timer.
  • Control, operators, variables, lists and My Blocks (they become async def functions).

Blocks with no Python version (like app sounds) get a # TODO so nothing disappears silently. Tested against real SPIKE App project files and LEGO's own Training Camp programs.
